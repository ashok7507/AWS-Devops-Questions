### 1. What is Amazon S3?  
Ans:  Amazon S3 stand for (Simple Storage Service) is a cloud-based object storage service provided by Amazon Web Services (AWS).  
It allows you to store, retrieve, and manage files/data over the internet.  
Highly scalable and durable (Highly scalable means a system can handle increasing workload, data, or users by expanding its  resources/capacity.) (Data is protected against loss or corruption)  
Commonly used for backups, websites, data lakes, application files, and media storage

### 3. What is an S3 Bucket?
Ans:  An S3 bucket is a container used to store objects (files/data) in Amazon S3.    
Think of a bucket like a folder or storage container in the cloud where you keep your files.

### 5.  What are different types of s3 bucket?
Ans:  
#### General Purpose:  
With a General Purpose S3 bucket, you can store many kinds of data, such as photos, videos, csv file etc. and S3 automatically stores data across multiple Availability Zones within the AWS Region. General workloads data in this bucket.  
#### Directory Bucket:-   
A directory bucket stores data in a single Availability Zone and is designed to provide very low-latency, high-performance access to S3  data.  High-performance workloads in this bucket.  
#### Table Bucket:-  
Istead of storing normal files such as images, videos, or PDFs, a table bucket is mainly used for storing structured data in rows and  columns format for analytics and data leke workload.  
( Analytics working on row data and finding useful information , data lake means it is one kind of place to store large amounts of data.)  

### 4. What is s3 Object?    
Ans: An S3 Object is the actual piece of data/file like as jpg, viodeos, pdf, csv, table data that you store inside an S3 bucket.  

### 5. What is S3 Versioning?  
Ans:  S3 Versioning is a feature in Amazon S3 that keeps multiple versions of the same object when you upload or modify it.  
and also we can say like Versioning means S3 keeps the old versions of your file instead of permanently replacing them.  

### 6. What is s3 bucket lifecycle policies?  
Ans:  An S3 Lifecycle Policy is a set of rules that automatically manages objects in an S3 bucket as they get older. Automatically move or delete files based on their age or other conditions.  

### 7. What is ACL in bucket?  
Ans: ACL stands for Access Control List. An S3 ACL is a way to control who can access a bucket or an object and what they are allowed to do. and also we can say like it is a list of permissions that tells S3 who can access your data and what they can do with it.  

### 8. What is SSE and CSE?  
Ans:  SSE (Server-Side Encryption) means AWS encrypts the data on the server side before storing it into s3. and CSE (Client-Side Encryption) means your application encrypts the data before uploading it to S3.  

## 9. What is the maximum size of an S3 object?  
Ans:  The maximum size of a single Amazon S3 object is 5 TiB (5,497,558,138,880 bytes).  

## 10. What is the maximum number of objects that can be stored in an S3 bucket?  
Ans:  There is no fixed maximum number of objects in s3 bucket.  

## 11. What is the difference between S3 and EBS?  
Ans:  S3 is an object storage service used to store files like images, videos, documents, whereas EBS is block storage that provides a disk for EC2 instances.  

## 12. What is the difference between S3 and EFS?  
Ans:  S3 is an object storage service used to store files like images, videos, documents, while EFS is a shared file system that can be mounted and used by multiple EC2 instances.  

## 13. What are the different S3 Storage Classes?  
Ans:  S3 provides different storage classes such as Standard, Intelligent-Tiering, Standard-IA, One Zone-IA, Glacier Instant Retrieval, Glacier Flexible Retrieval, and Glacier Deep Archive, allowing us to choose storage based on access frequency and cost.  
#### Standard :  
S3 Standard is the default storage class used for frequently accessed data. It provides high durability, high availability, and fast access to objects  
#### S3 Standard – Infrequent Access:  
Less frequently used but need fast access so at that time we use S3 Standard Infrequent Access class.  
#### S3 One Zone – Infrequent Access:  
S3 One Zone-IA is used for infrequently accessed data that can be stored in a single Availability Zone. It is cheaper than Standard-IA but has higher risk because the data is stored in only one AZ.  
when we need Infrequent access + one AZ + lower cost so we can go with this class.  
#### S3 Intelligent:  
This class automatically moves object from one class to another class to help reduce storage costs.  
S3 Glacier Instant Retrieval:  
Archive data that is rarely accessed but needs immediate access when required.  
#### S3 Glacier Flexible Retrieval:  
Used for Archive data that is rarely accessed and doesn't need immediate access.  
#### S3 Glacier Deep Archive:  
Used for Data that is very rarely accessed and needs to be stored for a long time.
