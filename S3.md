1. What is Amazon S3?
Ans:  Amazon S3 stand for (Simple Storage Service) is a cloud-based object storage service provided by Amazon Web Services (AWS).
It allows you to store, retrieve, and manage files/data over the internet.
Highly scalable and durable (Highly scalable means a system can handle increasing workload, data, or users by expanding its resources/capacity.) (Data is protected against loss or corruption)
Commonly used for backups, websites, data lakes, application files, and media storage

2. What is an S3 Bucket?  
Ans:  An S3 bucket is a container used to store objects (files/data) in Amazon S3.    
Think of a bucket like a folder or storage container in the cloud where you keep your files.

3.  What are different types of s3 bucket?
Ans:
General Purpose:-
With a General Purpose S3 bucket, you can store many kinds of data, such as photos, videos, csv file etc. and S3 automatically stores data  across multiple Availability Zones within the AWS Region. General workloads data in this bucket.
Directory Bucket:- 
A directory bucket stores data in a single Availability Zone and is designed to provide very low-latency, high-performance access to S3 data.  High-performance workloads in this bucket.
Table Bucket:-
Istead of storing normal files such as images, videos, or PDFs, a table bucket is mainly used for storing structured data in rows and columns format for analytics and data leke workload.
( Analytics working on row data and finding useful information , data lake means it is one kind of place to store large amounts of data.)
